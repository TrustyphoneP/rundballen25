{% comment %} Vollbild-Overlay mit Spinner für lange Vorgänge (Beleg-Analyse). Erwartet eine Alpine-Variable `analyseLaeuft` im umgebenden x-data-Scope und muss INNERHALB des Elements mit x-data eingebunden werden. x-teleport="body" verschiebt das Overlay beim Rendern direkt unter . Das ist nötig, weil position:fixed sonst von Vorfahren mit backdrop-filter oder transform eingefangen wird (die Topbar in base.html nutzt backdrop-filter:blur) -- das Overlay würde dann in diesem Element kleben statt den Viewport zu füllen. Der Alpine-Scope (analyseLaeuft) bleibt beim Teleport erhalten. {% endcomment %}
